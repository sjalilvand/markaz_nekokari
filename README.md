# داشبورد جامع مراکز نیکوکاری و توانمندسازی

سامانه تحلیل عملکرد مراکز نیکوکاری در شبکه‌های مردمی — با **بک‌اند Flask + SQLite** و **فرانت‌اند React + ECharts**، کاملاً راست‌به‌چپ و فارسی.

## معماری

```
backend/          Flask REST API + SQLite + ماژول‌های داده
  app.py          همه Endpointهای API + سرو فایل‌های build فرانت
  db.py           طرح جداول و شاخص‌های پایگاه داده
  generator.py    مولد داده نمونه وفادار به آمار واقعی فایل‌های CSV
  importer.py     واردکننده CSV با تشخیص خودکار کدگذاری (UTF-8 / Windows-1256)
                  و نگاشت خودکار ۲۵ اسکیمای شناخته‌شده سامانه نیکوکاری
  narrative.py    مولد گزارش متنی تحلیلی + موتور بینش‌ها و پیشنهاد بهبود
  constants.py    توزیع‌های واقعی استخراج‌شده از گزارش تحلیل فایل‌ها
  norm.py         نرمال‌سازی متن فارسی (ي/ک عربی، ارقام، فاصله‌ها)
frontend/         React 18 + Vite + ECharts + فونت وزیرمتن
```

## راه‌اندازی سریع

```bash
# بک‌اند
cd backend
pip install -r requirements.txt
python generator.py          # ساخت پایگاه داده نمونه (وفادار به آمار فایل‌های واقعی)
python app.py                # اجرای سرور روی پورت 8000

# فرانت‌اند
cd ../frontend
npm install
npm run build                # خروجی در dist/ و سرو توسط همان Flask
```

سپس مرورگر: `http://localhost:8000`

### وارد کردن فایل‌های CSV واقعی

از صفحه «بارگذاری و کیفیت داده» در سامانه فایل‌های CSV خود را بارگذاری کنید، یا:

```bash
cd backend
python importer.py /path/to/csv/folder
```

- کدگذاری (UTF-8 / UTF-8-sig / Windows-1256) به‌طور خودکار تشخیص داده می‌شود.
- ستون‌ها با نام‌های مستعار نگاشت می‌شوند (مثل «مرکز نیکوکاری و توانمندسازی»، «شماره مجوز»، «کدملی» و…).
- فایل‌های شناخته‌شده: New.csv، NK_HAMYARAN REPORT، NK_NIAZMANDAN REP، Report.csv، گزارش‌های
  پرداخت/دریافت نقدی و غیرنقدی، گزارش به تفکیک فعالیت و مرکز، کارتکس مراکز و اعضا، شبکه‌سازی،
  تعریف پک، جبران خدمات به تفکیک استان، تراکنش‌های ثبت‌نشده، گزارش کلی، نیکوکاران حقوقی و…
- پس از بارگذاری، امتیاز و مدال مراکز بازمحاسبه می‌شود.

## ویژگی‌ها

- **۹ داشبورد**: مدیریتی، تحلیلی و توصیفی، روند پرداخت‌ها و مقایسه سال، عملکرد استان‌ها،
  مراکز و مدال‌ها، شاخص‌های کلیدی (KPI)، گزارش‌های قابل فیلتر، گزارش متنی، کیفیت داده.
- **قابلیت‌های Power BI**: اسلایسرهای سراسری (سال/استان/اداره)، فیلتر متقاطع با کلیک روی نمودارها،
  Drill-down، جدول محوری (Pivot) با نقشه حرارتی، Bookmarks (نماهای ذخیره‌شده)، خروجی PNG هر نمودار،
  خروجی CSV/اکسل، چاپ و PDF، پوسته روشن/تاریک.
- **مدال‌دهی مراکز**: امتیاز مرکب (ساختار + فعالیت مالی + پوشش نیازمندان + کیفیت اعضا) و مدال‌های
  پلاتین/طلا/نقره/برنز + «نیازمند بهبود» با شفافیت معیارها.
- **KPIهای کامل**: نسبت دریافت به پرداخت، سهم پرداخت نقدی، میانگین اعضای فعال، پوشش مدیر اجرایی،
  همیار به ازای هزار نیازمند، تمرکز دهک ۱-۲، تکمیل کدملی، رشد سالانه هم‌دوره‌ای، تمرکز جغرافیایی،
  تراکنش‌های ثبت‌نشده و…
- **موتور بینش**: قواعد تحلیلی روی داده زنده (ضعف/قوت/پیشنهاد با اقدام مشخص).
- **گزارش متنی خودکار**: ۹ بخش تحلیلی با ارقام زنده پایگاه داده + چاپ/PDF.
- **کیفیت داده**: درصد خالی‌ها، تراکنش‌های ثبت‌نشده، مطابقت با ارقام مرجع فایل مالی استانی.

## API (خلاصه)

| مسیر | توضیح |
|---|---|
| `/api/meta` | استان‌ها، ادارات، سال‌ها، جمع کل‌ها |
| `/api/overview` | کارت‌های KPI، روند ماهانه، استان‌های برتر، بینش‌ها |
| `/api/demographics` | سن، دهک، جنسیت، نوع و گروه نیازمندی |
| `/api/payments/trend` | روند ماهانه + میانگین متحرک + سالانه |
| `/api/payments/compare` | مقایسه سالانه و ماتریس استان×سال |
| `/api/provinces` | رتبه‌بندی استان‌ها با معیارهای مختلف |
| `/api/centers` و `/api/centers/summary` | فهرست، جست‌وجو، امتیاز و مدال مراکز |
| `/api/kpis` | کارنامه کامل شاخص‌های کلیدی |
| `/api/records` `/api/pivot` `/api/export/csv` | گزارش‌های قابل فیلتر، Pivot و خروجی |
| `/api/narrative` `/api/insights` | گزارش متنی و بینش‌ها |
| `/api/quality` `/api/import` | کیفیت داده و بارگذاری CSV |

## یادداشت داده‌ها

تا زمانی که فایل‌های CSV واقعی بارگذاری شوند، سامانه با «داده نمونه کالیبره‌شده» کار می‌کند:
توزیع‌ها (استان‌ها، سن، دهک، نوع نیازمند، درخواست‌ها و مبالغ مالی) عیناً از گزارش تحلیل فایل‌های واقعی
بازتولید شده و جمع مبالغ مالی دقیقاً با ارقام فایل «گزارش دریافت و پرداخت به تفکیک استان»
(پرداخت نقدی ۱۳٬۲۰۸ میلیارد، پرداخت غیرنقدی ۵۴٬۲۸۸ میلیارد، دریافت نقدی ۴۷٬۲۲۶ میلیارد و
دریافت غیرنقدی ۷۶٬۶۵۲ میلیارد ریال) تراز شده است.
